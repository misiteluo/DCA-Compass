# 定投罗盘 · DCA Compass

五资产智能定投评分站：每天给 BTC / 黄金 / 纳斯达克100 / 标普500 / 沪深300 打一个 0-100 的估值分，并映射成当期定投倍数（0.2x-3.0x）。

原创实现，功能对标 btcdca.me（DCA HUB）：多维度指标 → 历史百分位归一化 → 加权综合分 → 倍数映射 → 与普通定投 / 买入持有的历史回测对比。另含懒人组合（6 个经典组合真实回测）与美股 QDII 基金清单页。

## 方法

- 维度（全部由价格序列导出）：MA200 偏离、MA50 偏离、RSI(14)、布林带 %B、距 52 周高点回撤、20 日波动率、3 年价格位置、MACD；BTC 额外含 AHR999 风格维度。每维度取当前值在自身全部历史中的百分位，映射为 0-100 分（越便宜分越高），权重合计 100%。
- 倍数映射（全站统一，分段线性）：0 分→0.2x，30→0.5x，50→0.8x，70→1.2x，85→1.95x，100→3.0x。区间：0-30 高估 / 30-50 偏高估 / 50-70 合理 / 70-85 低估 / 85-100 极度低估。
- 回测：每周定投，基准 100/周，策略定投金额 = 基准 × 当日倍数（评分只用当日及之前数据，无未来函数），与普通定投、买入持有并列对比。
- 数据源：Yahoo Finance chart API（BTC-USD、GC=F、QQQ、SPY、510300.SS），Stooq CSV 为备用源。

## 运行

```bash
# 重新抓取数据、计算评分与回测、生成站点（纯 Python 标准库，零依赖）
python3 pipeline/build_data.py

# 本地预览
python3 -m http.server 8931 -d site
```

`data.json` 是全站唯一数据源，首页与各资产页共用，保证数字一致。

## 结构

- `pipeline/build_data.py` — 抓取 → 评分 → 回测 → 生成 `data.json` + 全部 HTML
- `site/` — 生成的静态站（index、btc、gold、nasdaq、sp500、hs300、lazy、funds）
- `BUILD_REPORT.md` — 最近一次构建的数据与验证报告

本项目仅为历史数据回测与定投纪律工具，不构成投资建议。
